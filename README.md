# 三国杀 · 军争（网页版原型）

一个可本地联机的三国杀军争网页原型：五人 / 八人、房间码、随机匹配、机器人补位、
主公选将、三选一、五秒换牌、军争牌堆、32 名武将、牌堆 / 武将图鉴。

## 启动

```bash
cd sgs
node server.js
```

然后打开：<http://127.0.0.1:3000>

- 默认端口 3000，可用 `PORT=3001 node server.js` 改端口。
- 默认监听 `127.0.0.1`，同一台机器可开多个浏览器标签/窗口联机。
- 房间与对局保存在内存里，重启服务会清空。

## 手机 / 局域网访问

默认只监听 `127.0.0.1`，手机打不开（手机上的 `127.0.0.1` 指手机自己）。要同 Wi-Fi 手机访问：

1. 在电脑上查局域网 IP：`ipconfig`，找 WLAN / 以太网的 IPv4 地址（例如 `10.180.81.130`）。
2. 用局域网模式重启服务：
   ```powershell
   $env:HOST='0.0.0.0'; node server.js
   ```
3. 如果 Windows 防火墙弹窗，选择“允许访问”（专用网络）；没有弹窗就用管理员 PowerShell 放行 TCP 3000：
   ```powershell
   New-NetFirewallRule -DisplayName "Sanguosha 3000" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow -Profile Private
   ```
4. 手机浏览器打开 `http://<电脑局域网IP>:3000`。

注意：
- 手机和电脑必须在同一 Wi-Fi；公司 / 校园 / 酒店 Wi-Fi 可能开启 AP 隔离，设备之间不能互访。
- 手机用流量或不同网络时，局域网 IP 不可达，需要公网部署或 Cloudflare Tunnel / ngrok 之类的隧道。
- 当前没有账号体系，只靠房间码和令牌；不要直接把 3000 端口暴露到公网。

## 已实现

- **大厅**：输入昵称；五人 / 八人军争；创建房间（8 位房间码）、房间码加入、随机匹配。
- **房间**：房主可添加 / 移除机器人；人齐后房主开始。
- **身份**：随机抽主公，其余身份与座位随机分配；主公体力上限 +1。
- **选将前**：每名玩家能看到自己的身份和座次；座次是对局实际座次（主公固定 1 号，其余随机），其他人的身份只公开主公。
- **选将**：主公可从全部主公将 + 3 名随机非主公将中选择；其余玩家每人 3 张不同武将三选一。
- **开局**：发 4 张手牌，5 秒看牌，可换牌一次（限一次）。
- **对局**：准备 / 判定 / 摸牌 / 出牌 / 弃牌 / 结束阶段；距离、攻击范围、判定、濒死求桃、
  无懈可击、铁索传导、装备、延时锦囊、胜负判定、终局亮出所有手牌。
- **电脑节奏**：电脑每次行动间隔约 2 秒，避免连续动作过快。
- **出牌动画**：使用牌时屏幕中央展示牌面；普通牌随后消失，装备牌会飞向该玩家的装备区。
- **摸牌动画**：摸牌时牌背从牌堆飞向该玩家的手牌区或座位。
- **选牌操作**：出牌阶段先点一张可用的牌（选中的牌会亮起并浮动），再点目标玩家使用；目标不合法会弹出提示；响应牌仍然点一下就能出；左键再次点击已选中的牌可以取消选中。
- **装备区**：每个座位公开显示武器 / 防具 / +1 马 / -1 马四个装备槽，以及实时手牌数量（暗置）；右键装备查看牌面效果，右键其他玩家头像查看其技能。
- **座次**：对局中每名武将下方标出实际座次，与选将时报的座次一致。
- **思考时间**：每次行动 / 响应有 30 秒倒计时（右上角显示）；出牌或发动技能后重新计时，超时按默认处理。
- **立绘**：从你提供的 32 张武将卡里裁出立绘，显示在座位头像、选将卡和图鉴上，与武将名一起出现。
- **技能面板**：对局中常驻显示自己的技能；右键技能查看完整描述；主动技用 ◆ / 主动技标识，只有在当前可发动时才亮起「可发动」，左键点击发动；时机不对时不亮、也不能点。获得技（【看破】【博图】等）带金色标记，主公技只对主公显示。
- **手牌排版**：牌名改为从左到右、从上到下（不再竖排）；牌面按牌名 / 类型加了 SVG 徽记水印。
- **牌堆**：150 张军争风格牌堆，含兵粮寸断、火攻、铁索连环、闪电、酒、火杀 / 雷杀、
  各类武器 / 防具 / 坐骑。
- **图鉴**：32 名武将技能（含获得技标记）、牌堆构成与牌面说明。

## 技能实现说明

32 名武将均可选、技能可实际参与对局。重点机制说明：

- **观星**：观看牌堆顶 3 / 5 张（仅自己可见），拖动排序后选择置顶 / 置底；全部置底时回合结束可再次发动。
- **鬼才**：判定前观看牌堆顶 X 张（X 为体力上限，仅自己可见），先用手牌替换一张，再拖动调整顺序；第一张为本次判定牌。
- **跨角色手牌**：顺手 / 过河 / 反馈 / 突袭 / 谋诛 / 除疠等选择其他玩家手牌时暗置为牌背；装备 / 判定区公开；五谷 / 火攻按规则公开。
- **反间 / 密诏拼点 / 离魂 / 五谷**：有选牌 / 拼点弹层。
- **无懈可击**：最多 3 层；黄月英【看破】转化出的无懈不可被响应。
- **获得技**：【看破】通过【奇才】条件获得；【博图】通过【勤学】觉醒获得；两者在技能面板和图鉴里都带特殊标记。主公技只给主公生效。
- **奋威**：甘宁的【奋威】支持【南蛮入侵】【万箭齐发】，也支持【五谷丰登】【桃园结义】，可取消其中至多两个目标。
- **装备**：实现了诸葛连弩、青釭剑、青龙偃月刀、贯石斧、方天画戟、麒麟弓、寒冰剑、
  古锭刀、朱雀羽扇、八卦阵、仁王盾、藤甲、白银狮子、坐骑；雌雄双股剑 / 丈八蛇矛等做了简化。
- **部分技能**（孙权【救援】、部分“非锁定技失效”效果等）简化或未实现。
- 牌堆是 150 张的军争风格牌堆，不是官方 160 张的精确构成；后续可按官方牌表替换 `data.js`。

## 文件结构

```
sgs/
  data.js            武将、卡牌定义、牌堆生成
  engine.js          规则引擎：回合、判定、伤害、濒死、无懈、铁索、胜负
  skills.js          32 名武将的技能触发 / 主动技能
  rooms.js           房间、选将、身份、机器人、SSE 广播
  server.js          HTTP + SSE 服务
  public/
    index.html
    style.css
    app.js           前端渲染与交互
    portraits/       32 名武将的立绘（从上传的武将卡裁切）
  screenshots/       界面截图
  test.js            全机器人对局自测（引擎层）
  http-test.js       HTTP / SSE 流程测试（需服务运行）
```

## 自测

```bash
# 全机器人八人局 / 五人局（引擎层）
node test.js 8
node test.js 5

# 需要先启动 server.js
node http-test.js
```
